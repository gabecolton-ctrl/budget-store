# budget-store

Hosting for the budget storefront. The site is built from
[gabecolton-ctrl/txbio](https://github.com/gabecolton-ctrl/txbio) by
`tools/build-budget.py` (see `budget/README.md` there); this repo only holds
the publish workflow. It rebuilds every 30 minutes when txbio changes, or from
Actions → Publish → Run workflow.
